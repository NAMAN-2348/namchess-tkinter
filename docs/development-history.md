# Development history

This summary describes the submitted script iterations. It is not a claim that every milestone was fully completed or validated.

- **Iteration 1 (`archive/namchess-it1.py`)** — built the Tkinter chessboard and introduced piece-movement logic.
- **Iteration 2 (`archive/namchess-it2.py`)** — expanded movement implementation and turn handling. This is the baseline from which `main.py` was prepared.
- **Iteration 3 (`archive/namchess-it3.py`)** — experimented with tracking attacks on the king and detecting check/checkmate.
- **Iteration 4 (`archive/namchess-it4.py`)** — continued the check/king-safety experiment and added a move-log list and attempted move rollback. These experiments have defects and are preserved for reference, not used as the runnable baseline.
- **Current baseline (`main.py`)** — based on iteration 2, with corrected pawn-forward/capture handling and the chess-symbol font name fixed.

The uploaded `CHESS TK.py` file duplicates iteration 2 and is not archived separately. `CHESS TK(pcp).py` and `CHESS TK(chknmt).py` are partial extracts rather than complete programs, so they are intentionally excluded.
